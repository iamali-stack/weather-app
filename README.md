# Weather App 🌤️

A sleek weather app showing current conditions and 3-day forecasts. Features real-time weather data, location detection, and city search. Built with HTML, CSS, and JavaScript.

## Features ✨

- **Current Weather Display**
  - Temperature in Celsius
  - Weather condition with appropriate icons
  - Humidity percentage
  - Wind speed and direction
  - City name

- **3-Day Forecast**
  - Today's weather
  - Tomorrow's forecast
  - Day after tomorrow's forecast
  - Each day includes:
    - Temperature
    - Minimum temperature
    - Weather condition with matching icons

- **User-Friendly Interface**
  - Clean, modern design
  - Responsive layout for all devices
  - Intuitive navigation
  - Weather icons for different conditions
  - Easy-to-read weather information

- **Search Functionality**
  - Search for any city worldwide
  - Real-time weather updates
  - Error handling for invalid locations

- **Automatic Location Detection**
  - Gets weather for user's current location
  - Fallback to default location if permission denied

## Weather Conditions Supported 🌦️

- Sunny
- Clear
- Partly Cloudy
- Cloudy/Overcast
- Rain (Light, Moderate, Heavy)
- Thunderstorm
- And more...

## Technologies Used 💻

- HTML5
- CSS3
- JavaScript (ES6+)
- Weather API Integration
- Bootstrap 5
- Font Awesome Icons

## How to Use 📱

1. Open the app in your web browser
2. The app will automatically try to detect your location
3. To search for a different location:
   - Enter the city name in the search bar
   - Click the search button or press Enter
4. View the current weather and 3-day forecast
5. Click the logo or "Home" to refresh the page

## API Used 🌐

This app uses the WeatherAPI.com service to fetch real-time weather data and forecasts.
